# Commit Changes

Read `ai-docs/agent-context/git-workflow.md` to understand the commit convention before committing.

Then:
1. Run git status to see changed files
2. Group files by service/scope
3. Create separate commits following the format in git-workflow.md
4. Do not push — local commits only
5. Report the list of commits created
